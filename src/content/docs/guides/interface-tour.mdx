title: Interface tour
description: Find your way around the Buildworks catalogue, inspector, and separate Planning Mode workspace.
---

The catalogue and Planning Mode have different jobs. The catalogue helps you find and build one object. Planning Mode manages a whole blueprint, with its own smaller catalogue beside the world view.

## Open the catalogue

Press **F7** (rebindable in Mod Options) or use the Build button drawer on the game toolbar. If definitions are still loading, an early F7 press is queued and opens the catalogue when loading finishes. The server's **ReplaceBuildMenu** setting decides whether Knox or the vanilla Building Menu is the primary Build button action.

## Main catalogue

| Area | What to do there |
| --- | --- |
| Search and scope | Search by name, requirements, or everything. Switch between All, Favorites, and Recent. |
| Browse | Choose a category and then a subcategory. Filter by materials, skills, and readiness; **All qualities** also reveals normally hidden construction levels. |
| Results | Switch between grid and detailed list. A green readiness cue marks locally buildable entries. Pin or favorite an entry from its card or inspector. Hover over the magnifier to enlarge its tile image. |
| Inspector | See the selected buildable, its footprint, description, stage and available variants, materials and finishes. **Materials & tools** and **Skills & knowledge** remain together here. |
| Ingredient details | Select a requirement to see actual matching inventory under **Available Ingredients** and accepted alternatives under **Possible Items**. These details appear beside the inspector. |
| Actions | **Build** starts placement. **Place Plan** creates a planned ghost. |

The catalogue can be resized. Compact mode keeps browsing light: hover a buildable for its details rather than keeping the full inspector open. Appearance and preview sizes can be changed with the gear button; changes apply while you adjust them.

Read [Using the catalogue](../catalogue/) for matching items, filters, and pins.
You can also right-click a world tile and use **Find this piece in Knox Buildworks**; an empty opening offers **Find doors/windows for this opening** to narrow compatible choices.

## Planning Mode

Planning Mode keeps two windows over the world. The workspace on the **left** manages the blueprint; its dedicated catalogue sits on the **right**. It does not open the large main catalogue inside the workspace.

| Workspace control | Purpose |
| --- | --- |
| Plans | Create, select, rename, duplicate, share, import, export, or delete blueprints. Preview the full layout before placing it. |
| Pieces | Review planned objects, remove a selected pending piece, and choose build or erase tools. |
| Rooms | Draw, recolor, update, or erase room zones. |
| Supplies | Set the gather area used to count nearby materials. |
| Level and ghosts | Plan on another Z level and adjust ghost visibility. |

The **planning catalogue** has search, category and subcategory selectors, an All qualities toggle, and buildable results. After selecting one, use its arrows to move through stages, variants, materials, and finishes, then choose **Add to plan**. The selected combination is saved with the planned piece.

See [Planning Mode](../planning-mode/) and [Blueprints and access](../blueprints-and-access/) for the full workflow.

## Settings

The catalogue gear contains local appearance and browsing preferences: panel opacity and tone, contrast, icon and hover-preview size, tile backgrounds, and pinned-tracker layout. F7, toolbar visibility, planning inventory visibility, debug logging, and profiling live in **Mod Options > Knox Buildworks**. Server rules such as planning availability, well water, and paint requirements live in sandbox settings. See [Server configuration](../server-configuration/).
