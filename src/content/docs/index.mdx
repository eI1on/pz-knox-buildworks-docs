## What Knox owns

| Area | Knox Buildworks responsibility |
| --- | --- |
| Content | JSON definition registry, templates, groups, variants, materials and stage resolution |
| UI | Catalogue, ingredient drawer, requirement panels, pinned recipes and Planning Mode |
| Placement | Ghost preview, geometry matrix, support, collision and frame validation, timed construction |
| Planning | Rooms, gather areas, exported blueprints, build queues and stacked-plan selection |
| Multiplayer | Definition integrity, server-side validation, blueprint synchronization and access |

:::tip[Build 42 first]
All terminology and API behaviour in this site is tied to the current Build 42
mod source. If a generated vanilla entity component is not documented as
supported, treat it as metadata rather than assuming that copying it to JSON
will activate it.
:::
